# 全息感知黑盒套件 (Alife.BlackBoxSuite)

> 专注体征记账 × 双轨分层存储 × 毫秒边缘唤醒 × 离线视觉门禁 × 触发规则引擎 × 桌宠灵犀主动赋能

---

## 一、套件定位与双轨哲学
1. 底层绝对静默记账：六维体征（应用前台与同屏伴读、键盘节拍与滚轮、鼠标动力学、声卡会话峰值与 GSMTC 原生媒体、外设与文件脉搏、轻量离线视觉感知）在底层静默高精度采样与防抖入库，平时不产生任何无效汇报弹窗，杜绝上下文污染与大模型 KV Cache 显存击穿。
2. 双轨数据分层架构：
   - 长期核心资产（永久落盘）：剪贴板知识库与上下文截图闪存库（自动关联窗口标题标签）、每日应用画像（按天统计全天时长、全屏专注、同屏伴读与 Ctrl+S 产出）。
   - 瞬态体征切片（内存滑动队列）：击键节拍、滚轮强度、鼠标甩动/沉思/连点、声卡进程峰值、外设连断与文件脉搏仅在内存滑动（默认上限 300 条，关机自清，零磁盘垃圾）。
3. 纯节拍隐私绝缘：低级键盘钩子仅统计击键频次与退格次数（APM 与纠错比率），底层严禁记录任何按键键码与字符内容；剪贴板密钥正则自动脱敏（GitHub Token、OpenAI Key 等）。

## 二、核心感知与智能门禁 (v5.50 新特性)

1. 轻量离线视觉感知引擎 (YuNet)
   - 零云端依赖：内置轻量级 ONNX 人脸检测模型（face_detection_yunet_2023mar.onnx，仅 227KB），完全本地 CPU 推理，单帧耗时仅 20ms。
   - 单线程能效锁：严格锁定 OpenCV 单线程检测，消除 16 线程算力争抢病灶，单核占用自 115% 骤降至 20%，整机占用不到 2%。
   - 36px 物理尺度闸门：严格过滤画面中红色福字、海报动漫小人等微小目标（尺寸差达 85 倍），彻底根除误识假脸。

2. 真离席静默护栏 (Away Silence Gate)
   - 联动人脸感知与时间回滞机制。当视觉持续确认用户不在工位时，自动静音各类前台主动打扰与关怀播报，杜绝向空椅子自言自语。

3. 在座久坐监测门禁 (Seated Idle Monitor)
   - 人脸在场 + 键鼠静止双重仲裁，精准捕捉用户坐在电脑前长时间发呆、看课件或陷入长考的状态，触发关怀提醒。

4. 实时体征单板块分流 (QueryCurrentActivity Section)
   - 提供按板块条件查询能力：支持 `焦点`、`输入`、`空闲`、`音频`、`外设`、`剪贴板` 六大板块按需获取，大幅收敛模型上下文损耗。

5. 提示词三档分级注入 (Prompt Level)
   - 支持「完整 / 精简 / 关闭」三档模式，精简模式砍掉 73% 冗余文字，保留核心定位与底线守则，彻底守护大模型推理速度。

6. 触发规则引擎 (Triggers Engine)
   - 支持数值与文本条件比对、持续计时、快照单次、跨日自动清零与全模板宏置换，开放高级自动化联动。

## 三、四大主动提醒事件（主动赋能桌宠）
为前台桌宠装填毫秒级灵犀弹药，支持独立开关与自定义文案模板：
1. 毫秒级归座唤醒：底层微秒级边缘触发，用户重触物理按键瞬间秒唤桌宠。
2. 防误判真离席提醒：全屏专注与常规空闲双重仲裁，离席单次打标。
3. 音频端点切换与防社死：自动识别耳机拔插，扬声器切出时建议转静默纯文本。
4. 暴躁甩鼠标/卡壳告警：识别一秒内高频反转，感知写代码或阅读时卡壳应激。

## 四、未来宏伟演进路线图 (Roadmap: v6.0 ~ v7.0 深度神经感知)

> 「不仅要记录你的按键，更要读懂你的灵魂」—— 黑盒下一代全息感知蓝图

### 1. 视线追踪与代码聚焦点透视 (Gaze Tracking & Neural Focus Matrix)
- 瞳孔视线向量网络：利用微型前置镜头计算视线焦点（Gaze Point），推算用户正在注视屏幕的哪个物理区域（代码编辑区、控制台报错区、还是参考文档）。
- 桌宠灵犀共读：当桌宠想要开口前，先感知前辈的视线是否正聚焦在关键断点，彻底做到「你在看哪一行，我就懂你在想哪一行，绝不在你凝视代码时打断心流」。

### 2. 微表情疲劳动力学与心流熵值推演 (Micro-expression & Flow State Entropy)
- 眨眼节律与打哈欠动力学 (PERCLOS)：通过眼睑闭合时间比率与微表情张力，毫秒识别深层视觉疲劳与困意，主动递上深渊温茶与休息建议。
- 击键心流泊松分布：通过击键间隔微观方差（Variance of Inter-key Intervals），精准推算用户是处于行云流水的「心流爆发态」，还是频繁撤销退格的「困顿卡壳态」。

### 3. IDE 神经级脉搏与编译报错捕获 (Compiler Nerve & Semantic IDE Pulse)
- 源码缓冲区探针：无感穿透主流 IDE，毫秒捕获语法红线激增、测试用例红灯与未捕获异常调用栈。
- 报错即时蒸馏：在用户烦躁甩鼠标之前，黑盒已将堆栈核心报错提纯并挂载至桌宠上下文，桌宠第一时间递上精准的修复思路。

### 4. 跨现实生物体征融合 (Ambient IoT & Wearable Biometric Ingress)
- 智能穿戴心率与 HRV 联动：接入低功耗蓝牙手环，捕捉心率变异性（HRV），将真实生理应激水平化作黑盒第七维体征，打破赛博与现实的物理结界。

### 5. 零拷贝多智能体体征总线 (Zero-Copy Multi-Agent Telemetry Bus)
- 共享内存总线架构：基于 Memory-Mapped Files 实现微秒级体征广播，允许多个桌面眷属、辅助 Agent 与底层脚本以近乎零 CPU 开销共享全息快照。
